Mosqlimate Charts Playground

Every chart is a single <div>. All parameters, theme, sizing, and styling live as data-* attributes. One script tag initializes everything.

How it works

<!-- 1. Load echarts --> <script src="https://cdn.jsdelivr.net/npm/echarts@5.6.0/dist/echarts.min.js"></script> <!-- 2. Load @mosqlimate/core + auto-init --> <script type="module"> import { Mosqlimate } from "@mosqlimate/core"; Mosqlimate.autoInit(); </script> <!-- 3. Drop chart divs — everything is in the tag --> <div data-chart="rt" data-disease="dengue" data-geocode="2300507" data-start="2025-01-01" data-end="2025-12-31" data-theme="dark" data-background="#1a1a2e" data-border-radius="12px" data-padding="16px" ></div>

InfoDengue — Total Cases

Climate — Temperature

Climate — Humidity & Pressure

Conta Ovos — Positivity

Available data-* attributes

<!-- Chart selection (required) --> data-chart="rt | total-cases | temperature | accumulated-waterfall | umid-pressao-med | eggs-density | positivity | map | map-scatter" <!-- API params (chart-specific) --> data-disease="dengue | chik | zika" <!-- infodengue charts --> data-geocode="2300507" <!-- infodengue + climate --> data-start="2025-01-01" <!-- all charts --> data-end="2025-12-31" <!-- all charts --> data-uf="SP | RJ | MG | ..." <!-- contaovos charts --> <!-- SDK options --> data-theme="light | dark | minimal | publication | dashboard" data-width="800" <!-- optional, px --> data-height="400" <!-- optional, px --> data-api-base="https://..." <!-- override API URL --> <!-- Container styling (inline styles) --> data-background="#ffffff" data-border="1px solid #e5e7eb" data-border-radius="12px" data-padding="16px" data-font-family="monospace"

Web Component — <mosqlimate-chart>

Same API, encapsulated in a custom element with Shadow DOM. No data-* prefix — just plain attributes.

<!-- Usage --> <mosqlimate-chart chart="rt" disease="dengue" geocode="2300507" start="2025-01-01" end="2025-12-31" theme="dark" style="height:350px;" ></mosqlimate-chart> <!-- Register the element before use --> <script type="module"> import { registerChartElement } from "@mosqlimate/core"; registerChartElement(); </script>
